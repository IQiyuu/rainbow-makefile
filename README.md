# Rainbow Makefile 🌈

Un **Makefile coloré** permettant d'améliorer l'affichage des étapes de compilation dans le terminal.

Projet personnel réalisé dans le cadre de mon apprentissage de **Makefile** et des environnements Unix.

## Fonctionnalités

* 🌈 Affichage coloré dans le terminal
* 🔨 Compilation avec `make`
* 🧹 Nettoyage des fichiers générés
* 🔄 Recompilation du projet
* ✨ Messages personnalisés lors des différentes étapes

## Utilisation

Cloner le projet :

```bash
git clone https://github.com/IQiyuu/rainbow-makefile.git
cd rainbow-makefile
```

Puis utiliser le Makefile :

```bash
make
```

Autres commandes :

```bash
make clean
make fclean
make re
```

## Objectif

L'objectif est principalement d'expérimenter avec :

* GNU Make
* Variables Makefile
* Règles et dépendances
* Couleurs ANSI
* Affichage personnalisé dans le terminal
* Automatisation de tâches

## Compatibilité

Le Makefile a principalement été développé et testé dans un environnement Unix avec le terminal VS Code.

> ⚠️ La première version peut avoir quelques différences de comportement selon le shell ou le terminal utilisé.
